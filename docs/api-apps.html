App 列表接口文档

Base URL：http://127.0.0.1:8024  ·  路径前缀：/api/apps

说明：本接口以 apps/packages/manifest.json 为数据源，提供 App 列表的 查询与更新。所有响应为 JSON，已开启 CORS（Access-Control-Allow-Origin: *）。 接口约定与仓库内其他 api/* 处理器一致（导出 async function handler(req, res)）。

一、快速开始

启动本地 Node 服务（写操作需 APPS_API_WRITE=1）：

APPS_API_WRITE=1 node scripts/video-resolver-server.cjs
# 默认端口 8024，可用 PORT=xxxx 覆盖

接口在线地址：GET http://127.0.0.1:8024/api/apps

二、接口列表

方法路径说明
GET/api/apps列出全部 App，支持 ?platform= / ?q= 过滤
GET/api/apps?id=按 id 获取单条（404 若不存在）
POST/api/apps新增或更新（upsert），body 需含 id + name
PUT/api/apps?id=整体替换某条（不存在返回 404）
PATCH/api/apps?id=局部合并更新字段
DELETE/api/apps?id=删除某条

三、查询参数

参数位置类型说明
platformquerystring按平台过滤（platformId），如 android。可选值见下文平台枚举
qquerystring关键字，匹配 name / id / platform / description / version
idquerystring （写/单条必填）App 唯一标识，格式 平台/slug，如 android/cn.wk.android.body.os

四、写保护

所有写操作（POST / PUT / PATCH / DELETE）需要环境变量 APPS_API_WRITE=1，否则返回：

HTTP 403
{ "status": "error", "error": "写操作被禁用。请在启动时设置环境变量 APPS_API_WRITE=1 后再试。",
  "hint": "APPS_API_WRITE=1 node scripts/video-resolver-server.cjs" }

五、数据模型

App 条目

字段类型必填说明
idstring是平台/slug，如 android/cn.wk.android.body.os
namestring写入必填展示名
platformIdstring否平台键；缺省从 id 前缀推断
platformstring否平台展示名，缺省由 platformId 推导
descriptionstring否简介
latest / versionsobject / array否最新版本与历史版本
hasHistoryboolean否是否有多版本
updatedAtstring否更新日期；写操作自动刷新为今天
betaqrobject否betaqr 分发渠道块（见下）

betaqr 分发渠道块（可选）

字段类型说明
idstringbetaqr 应用 id（应用管理 → 基本信息）
shortstring应用短链接；仅含字母、数字、_、-
tokenRefstring指向服务端密钥配置的逻辑键（对应 api_token）
enabledboolean是否启用 betaqr 分发，默认 true
安全约定：api_token 是密钥，绝不进 manifest，统一存放于服务端配置 （约定 .betaqr-env.json，不入库）。本接口只负责数据模型，不向 betaqr 发起任何请求。

六、请求 / 响应示例

GET 列表

GET /api/apps?platform=android

{
  "status": "success",
  "total": 1, "count": 1, "platform": "android", "q": "",
  "apps": [
    { "id": "android/cn.wk.android.body.os", "name": "Cn.Wk.Android.Body.Os",
      "platformId": "android", "version": "7(1.00.06)", "updatedAt": "2026-06-14" }
  ],
  "manifestVersion": "20260630150829", "updatedAt": "2026-06-14"
}

POST upsert（带 betaqr）

POST /api/apps
Content-Type: application/json

{
  "id": "android/cn.wk.android.body.os",
  "name": "Cn.Wk.Android.Body.Os",
  "platformId": "android",
  "betaqr": { "id": "AbC123Def456", "short": "bodyos", "tokenRef": "wk-default", "enabled": true }
}

→ 200 { "status": "success", "action": "updated", "app": { ... }, "updatedAt": "2026-09-22" }

PATCH 局部合并

PATCH /api/apps?id=android%2Fcn.wk.android.body.os
{ "betaqr": { "short": "bodyos2" } }
→ 200 { "status": "success", "action": "patched", "app": { ... } }

七、错误码

HTTP场景
400请求体非 JSON / 缺 id 或 name / 字段校验失败（如 betaqr.short 非法）
403写操作但未设置 APPS_API_WRITE=1
404按 id 取单条 / PUT / PATCH / DELETE 时 id 不存在
405不支持的 HTTP 方法
500服务端异常
