# GitHub Radar 自动化：从 Trending 到个人技术雷达

这篇 mock 模拟偏工具链的文章。它和已有 demo 文章共享 `Automation` 标签，用来测试标签筛选出现多篇结果时的布局。

## 技术雷达的价值

每天观察 Trending 不一定要追热点，更像是在给自己的技术直觉校准方向。自动化的意义是把重复收集交给脚本，把判断留给人。

## 检查项

点击 `Automation` 标签时，列表应该至少出现两篇文章。搜索 `radar` 或 `Trending` 应该只收敛到这篇。
